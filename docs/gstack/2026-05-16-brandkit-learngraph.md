# Brandkit: LearnGraph

Generated with `/brandkit` direction on 2026-05-16.

## Brand Strategy

LearnGraph is an AI-powered learning search engine. It turns a blank search box
into a visible learning map: browser agents research, lesson agents synthesize,
graph agents place concepts, and rewire agents expose missing prerequisites.

The brand should feel like a serious AI tool for learning: visual, inspectable,
graph-native, and polished enough for a hackathon demo stage.

## Core Metaphor

Emergence from a signal.

The learner types one subject. A graph grows outward from that signal. Wrong
answers reveal hidden structure and insert the missing node.

## Logo Direction

Use a reduced node-path mark:

- one central search point
- two branching nodes
- a cut-through path that suggests learning direction
- simple enough to work as an app icon or graph node badge

Avoid brain icons, graduation caps, mascots, and generic sparkle AI marks.

## Visual System

Mode: dark developer / builder, softened for education.

Palette:

- near-black canvas: `#07080d`
- elevated panel: `#11131c`
- graph ink: `#d9e2ff`
- primary signal: `#7c5cff`
- knowledge green: `#30d982`
- prerequisite amber: `#ffb020`
- research blue: `#4da3ff`
- lesson pink: `#ff6fae`

Typography:

- system sans for UI
- monospace only for agent event labels and protocol chips
- large sparse headings
- no tiny unreadable fake dashboard text

## Product Surface Principles

- Search is the entry point, not a secondary control.
- The graph is the product, so it should occupy the hero surface.
- Agent activity must be visible enough that judges understand the pipeline.
- Lesson cards should feel like micro-units: visual first, then quiz.
- The gallery proves generated lessons persist.
- Wrong answer state should feel like graph intelligence, not failure.

## Demo Moment

> You do not browse a curriculum. You grow one.
