# GStack Project Documents

This directory is the team-visible home for GStack planning artifacts for this repo.

Use it for:

- Office-hours design docs
- Product and system maps
- Engineering review plans
- Design review notes
- Hackathon demo scripts and handoff notes

Suggested naming:

- `YYYY-MM-DD-office-hours-<topic>.md`
- `YYYY-MM-DD-system-map-<topic>.md`
- `YYYY-MM-DD-eng-plan-<topic>.md`
- `YYYY-MM-DD-demo-script.md`

For this hackathon, keep the GBrain education-app plan here so teammates can review
and edit it in normal Git workflow.
